# Open Source SVG Illustration

Shadow Transfur Wolf is an open source vector illustration project featuring a dark latex wolf reaching toward a standing person through a gentle violet crystalline transfur connection. This non-violent fantasy artwork is delivered as an editable SVG graphic and is inspired by the transformation themes of the game Changed.

## Install

1. Download `dark-latex-wolf.svg` from the project repository or marketplace package.
2. Open the file in a modern web browser to view it.
3. For editing, open it in a vector graphics application that supports SVG files, such as Inkscape, Illustrator, or Affinity Designer.

## Use

1. Import `dark-latex-wolf.svg` into your design, presentation, webpage, or illustration project.
2. Resize the artwork as needed; the SVG uses vector paths and scales without losing quality.
3. Edit the gradients, colors, text, or individual shapes in a compatible vector editor.
4. Keep the artwork in SVG format when you want to preserve its editable layers and visual effects.

The illustration includes a dark background, violet lighting, a glossy black latex wolf, a calm human silhouette, reaching paws, crystalline energy, and the caption “DARK LATEX • GENTLE TRANSFUR.”
